Problem

Fraud teams need low-latency card scoring with model lineage, drift monitoring, audit logs, and safe promotion controls. A notebook model is not enough; the work is turning it into an observable and governable service.

Architecture

PaySim demo stream -> Event Hubs -> ADLS -> Databricks Bronze/Silver/Gold
IEEE-CIS training -> feature engineering -> MLflow champion/challenger
Feast + Postgres -> FastAPI on Azure Container Apps -> Grafana Cloud
PSI drift -> Airflow retraining DAG -> human approval gate -> promotion

Governance Choice

The model cannot promote itself. A challenger must pass automated metric gates and then wait for fraud_retrain_approval_<run_id> = approved. Automation recommends; a human approves; rollback steps are documented.

Business Framing

The portfolio framing is +23% fraud value caught at fixed 0.1% FPR versus a stale monthly baseline. This is a scenario-backed portfolio statement, not a claim of production validation on bank traffic.
